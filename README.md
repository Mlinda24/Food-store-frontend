# Foodie Express Mobile App

A comprehensive food delivery mobile application built with Flutter.

## Features

- **Multi-role Authentication** (Customer, Restaurant, Driver, Admin)
- **Restaurant Discovery** with search and filters
- **Menu Management** for restaurants
- **Order Tracking** with real-time status
- **Push Notifications** for order updates
- **User Profile** management
- **Dark/Light Theme** support

## Getting Started

### Prerequisites

- Flutter SDK (>=3.0.0)
- Dart SDK (>=3.0.0)
- Android Studio / VS Code
- iOS Simulator / Android Emulator
